二、共同约定 / Shared conventions
1. 下方输入顺序是 SQL 中每个 %s 的顺序，不一定等于 service 函数的参数顺序；重复值也要保留。
   Inputs follow each SQL %s position, not necessarily the public service argument order; repeated inputs are intentional.
2. 返回列按从左到右排列，Python 下标从 0 开始；返回字段名的别名可调整，但位置和类型不能自行改变。
   Columns are positional, starting at Python index 0; SQL aliases may differ, but positions and types must remain compatible.
3. 使用 psycopg2 的独立参数绑定，不拼接用户输入。/ Use separate psycopg2 parameter binding, without concatenating user input.
4. queries.py 只保存 SQL，不连接数据库、不接收菜单输入、不提交或回滚。service.py 负责这些操作。
   queries.py stores SQL only; service.py owns connections, rule checks, locks, commits and rollbacks.
5. 普通读取语句用于只读事务，不得附加更新锁；LOCK_ROOM 和 LOCK_RESERVATION 必须保留相应行锁。
   Ordinary reads run in read-only transactions; the two LOCK statements must preserve their respective row-update locks.
6. 日期为 date，金额为 Decimal 对应的 numeric，开放状态为 bool，实际时间为带时区 datetime。
   Types: planned dates = date; money = numeric/Decimal; open flags = bool; actual times = timezone-aware datetime.
   None = SQL NULL；空字符串 "" 与 None 不同。/ None means SQL NULL; an empty string is a different value.
